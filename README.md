# BiggyChez

BiggyChez is a browser-based Web Operating System (WebOS) created as part of the Stardance mission.

Built on top of the Stardance framework and tutorials, BiggyChez explores how modern operating system concepts can be recreated entirely in the browser using web technologies.

## Features

- Desktop-style user interface
- Window management system
- Application launcher
- Taskbar and navigation controls
- Browser-based file management
- Custom themes and styling
- Responsive design for desktop and laptop screens

## Mission

The goal of BiggyChez is to demonstrate that a fully interactive desktop environment can be delivered through a web browser without requiring traditional operating system installation.

This project was created to:

- Learn modern web development techniques
- Understand operating system user interface design
- Explore browser-based application architecture
- Customize and extend an existing WebOS platform
- Contribute to the growing community of WebOS creators

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Stardance WebOS Framework
